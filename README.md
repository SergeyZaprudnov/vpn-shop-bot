# 🤖 VPN Shop Bot

Telegram-бот для продажи VPN-подписок с приёмом оплаты через **ЮKassa**, админ-панелью и автоматическим управлением подписками.

## 📋 Возможности

### Для пользователей
- 💳 Покупка VPN-подписки на 30 дней через ЮKassa
- 📥 Автоматическое получение `.conf` файла после оплаты
- 📱 Пошаговые инструкции для Android, iOS, Windows и macOS
- 📋 Просмотр статуса подписки
- ⏰ Напоминание за 3 дня до окончания

### Для администратора
- 📊 Общая статистика: всего/онлайн/заблокировано + сумма оплат
- 👥 Список всех клиентов с их статусами
- 🔒 Блокировка / разблокировка
- ⏳ Продление (7, 30 или произвольное число дней)
- 🗑 Удаление клиентов
- 🔐 Доступ только для ADMIN_ID

### Автоматизация
- ⏰ Ежедневное напоминание за 3 дня до окончания
- 🚫 Автоблокировка при истечении подписки
- 💾 Запись платежей в БД

## 🛠️ Стек

| Компонент | Технология |
|-----------|------------|
| Язык | Python 3.11+ |
| Telegram Bot | aiogram 3.x |
| Веб-сервер | Flask |
| БД | SQLite (aiosqlite) |
| Платежи | ЮKassa API |
| Планировщик | APScheduler |
| VPN-панель | AmneziaWG Easy |
| Тесты | pytest + pytest-asyncio |
